# Security Policy

## Reporting a Vulnerability

If you find a security vulnerability in this module, please report it privately
by emailing **security@flousflow.com** instead of opening a public issue.

Please include:

* The affected module and Odoo version.
* Steps to reproduce.
* The impact of the issue.

We aim to respond within 5 business days.

## Scope

This policy applies to the `flousflow_accounting` module in this repository.
Odoo Community core and third-party modules are out of scope.
