Bank Statement Import for Odoo 20 Community

Import the statements your bank gives you, in the format it offers — CAMT.053, MT940, OFX, QIF, CSV or Excel — and reconcile them as usual. The journal is recognised from the account number in the file, the transactions already imported are left out, and the file stays attached to the statement.

CAMT.053 & MT940 OFX, QFX & QIF CSV & Excel maps Community Edition
Import

Whatever format your bank offers

Drop the files on the Import Statement button of the statement list, or on the card of a bank journal on the accounting dashboard. Each file is handed to the parsers in turn and read by the first one that recognises it, so you never have to say which format it is in.

  • ✓  CAMT.053, the ISO 20022 statement of the European banks.
  • ✓  MT940, the SWIFT statement, in its usual flavours.
  • ✓  OFX and QFX, the format of the online banking of North America.
  • ✓  QIF, with the format of its dates guessed from the values themselves, or written down when the file is ambiguous.
  • ✓  CSV and Excel, read through a map of the columns of your bank.
  • ✓  Several files at once, each one becoming its own statement.

File maps

Read the CSV of any bank, once and for all

A file map describes the export of one bank: how its text is encoded, how its numbers and dates are written, and which column holds what. Set the map on the journal of that bank and it is filled in by itself at every import.

  • ✓  Encoding, column separator and text delimiter, for a CSV or a TSV.
  • ✓  Decimal separator and thousands separator: 1,234.56 or 1.234,56 or 1 234,56.
  • ✓  Date format in the Python notation, rows to skip above the header, and the sheet to read of an Excel file.
  • ✓  Columns named by their header, or by their number when the file has none.
  • ✓  One signed amount column, or a debit column and a credit column — with the sign of the debits the way your bank writes them.
  • ✓  Label, reference, partner, counterpart account number, currency, notes and the identifier of the transaction at the bank.
  • ✓  A map belongs to one company, or is shared by all of them.
Safeguards

Nothing lands in the wrong journal, nothing lands twice

  • ✓  The journal is found from the bank account number written in the file; leave the journal empty and let the file decide.
  • ✓  A file imported in the journal of another account is refused, and so is a file whose currency is not the one of the journal.
  • ✓  The identifier of each transaction at the bank is kept, so importing the same file again brings in only what is new, and tells you how much was already there.
  • ✓  The same file can be imported in two journals of two companies without either of them skipping the transactions of the other.
  • ✓  The opening and closing balances of the file are carried over to the statement, and the file itself stays attached to it.
  • ✓  Partner name, counterpart account, reference and notes are kept on the transactions, which helps the reconciliation find its counterparts.
